INSTUCTION
В файле weather.py находится основной код моего бота.
В файле requirements находятся все нужные библиотеки которые стоит установить перед тем как запускать этот код.
Чтобы воспользоваться ботом нужно: 1)Скачать все указаные библиотеки в REQUIREMENTS 2)Запустить код weather.py 3)Зайти в телеграмм и найти бота по тегу @fafsssf_bot и написать ему команду /start
Этот бот умеет давать 3 дневные прогнозы и почасовые прогнозы погоды
Я пытался сделать бота автономным и не зависящим от непосредственного участия пользователя в запуске бота, но не нашёл адекватный хостинг.
Скачайте мою презентацию чтобы уидеть преимущества данного бота, что он умеет и что использовалось в написании.
